# Тематическое оформление светлой шапки

Текущие изображения: `sale-1111-light.webp`, `new-year-light.webp`,
`black-friday-light.webp`, `spring-light.webp` (1440×480, WebP).
Созданы встроенным инструментом imagegen; полные промпты — `prompts-light.json`.
Оптимизированные копии сохранены в этой папке, исходные PNG оставлены в хранилище генератора.

Светлый фон, натуральные материалы и фотографический декор. Новый год — хвоя,
ёлочные шары, снег и огни; весна — зелень и цветущие ветви; распродажи — подарки
и атласные ленты. В шапке декор находится рядом с названием акции, в отдельном
элементе без обработки нажатий. Так он остаётся узнаваемым и не закрывает навигацию.
Карточки в админ-панели используют те же изображения. Надписи и кнопки — HTML.

## Предыдущая версия

Созданы встроенным инструментом imagegen. Референс стиля: `public/banner4.png`.
Исходные PNG сохранены инструментом вне проекта; WebP в этой папке — оптимизированные копии для сайта.
Все надписи, ссылки и кнопки рисуются интерфейсом поверх фотографий.

Файлы: `sale-1111.webp`, `new-year.webp`, `black-friday.webp`, `spring.webp`.
Полные промпты каждого варианта: `prompts.json`.

Направление: реалистичная индустриальная фотография, графит, металл, дерево,
тёплый янтарный свет. Для Нового года добавлены хвоя и огни, для весны —
камень, дерево и зелёная ветка. Слева оставлена тёмная область для навигации.
